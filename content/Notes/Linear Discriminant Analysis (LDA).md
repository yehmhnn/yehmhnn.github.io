***

Linear Discriminant Analysis (LDA) is a supervised machine learning algorithm used for classification and dimensionality reduction, finding a linear combination of features that best separates two or more classes. 

- **Assumption:** Data in each class is Gaussian distributed, and all classes share the same covariance matrix $\Sigma$.
    
- **Goal:** Maximize the distance between mean vectors while minimizing the variance within each class.
    
- **Key Property:** The decision boundary is the hyperplane where the log-posteriors of two classes are equal.
