### New Workflow

1. **Edit & Preview (In iCloud):** 
	- Open iCloud Quartz folder
	- run `npx quartz build --serve`
	- Look at `localhost:8080`
    
2. **Publish (On Local Laptop):** 
	- instead `npx quartz sync`
	- Open local laptop Quartz folder
	- run `./deploy.sh`.
