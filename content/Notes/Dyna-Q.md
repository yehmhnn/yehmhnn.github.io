## The Definition (What)

**Dyna-Q** is a hybrid reinforcement learning (RL) framework that integrates **direct learning** from real-world experience with **planning** using an internal world model. It enables an agent to learn optimal policies significantly faster than standard model-free methods.

## Why It Is Important (Why)

In domains like robotics or self-driving systems, gathering real-world experience is slow, expensive, and risky. Dyna-Q solves this bottleneck by maximizing sample efficiency:

- **Squeezes Maximum Value from Data:** Every real interaction is used twice—once for direct updating and once to build a simulator.
    
- **Offline Practice:** The agent "imagines" future scenarios during downtime, drastically reducing the required number of physical trials.

## How It Works (How)

Dyna-Q operates by running a continuous loop where every single real-world action triggers 3 distinct mathematical phases: 
1. direct learning
2. model building
3. imaginary practice.

Here is how the math integrates directly into each step of the mechanism:

### Step 1: Direct Learning (Real-World Experience)

The agent takes an action in the actual environment and receives real feedback. It immediately uses this to update its knowledge base (the Q-table) using the standard [[Q-learning]] equation:

$$
Q(s, a) \leftarrow Q(s, a) + \alpha [R_{env} + \gamma \max_{a'} Q(s', a') - Q(s, a)]
$$

> **What is happening here:** The agent adjusts its value estimate for taking action $a$ in state $s$ based on the actual reward ($R_{env}$) and the actual next state ($s'$) handed to it by the real world.

### Step 2: Model Learning (Building the Simulator)

Using that exact same real-world interaction, the agent updates its internal "world model" (a look-up table) to remember how the environment behaves:

$$\text{Model}(s, a) \leftarrow (R_{env}, s')$$

> **What is happening here:** The agent records a mental note: _"When I was in state $s$ and did action $a$, the real world gave me reward $R_{env}$ and moved me to $s'$."_ No math is calculated here; it is strictly a data-storage step.

### Step 3: Planning (Imaginary Practice Loop)

Before taking its next real-world step, the agent pauses to practice in its head. It repeats the following two sub-steps $N$ times (where $N$ is a user-defined number of planning steps):

- **A. Query the Model:** The agent selects a state ($s_{sim}$) and action ($a_{sim}$) from its memory to simulate. There are three primary strategies for making this selection:

	- **Random Sampling (Standard Dyna-Q):** The agent picks any previously visited state-action pair completely at random. It is computationally cheap but highly inefficient in large environments.

$$
(R_{sim}, s'_{sim}) = \text{Model}(s_{sim}, a_{sim})
$$
	
    
	- [[Ordered Sweeps]]: (Forward/Backward Sweep)
	- [[Prioritized Sweeping]]

- **B. Simulated Update:** The agent runs the Q-learning equation again, but this time it uses the **hallucinated** outcomes generated by the model instead of the real world: ([[Planning Backup]])
    
$$
Q(s_{sim}, a_{sim}) \leftarrow Q(s_{sim}, a_{sim}) + \alpha [R_{sim} + \gamma \max_{a'} Q(s'_{sim}, a') - Q(s_{sim}, a_{sim})]
$$
    

### Variable Definitions

- **$Q(s, a)$**: The estimated long-term value of taking action $a$ in state $s$.
    
- **$\alpha$ (Alpha)**: The learning rate (how heavily the agent weights new experiences over past knowledge).
    
- **$\gamma$ (Gamma)**: The discount factor (how much the agent cares about future rewards vs. immediate rewards).
    
- **$\max_{a'} Q(s', a')$**: The highest possible value the agent expects it can get from the next state ($s'$) by choosing the best available action ($a'$).
    
- **$_{env}$ vs. $_{sim}$**: Subscripts denoting whether the data came from the actual **environment** or the internal **simulation**.

## Additional Insights

### A Direct Comparison: [[Q-Learning]] vs. Dyna-Q

| **Feature**            | **Standard Q-Learning (Model-Free)**                | **Dyna-Q (Model-Based Hybrid)**                                                                        |
| ---------------------- | --------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **Source of Learning** | Strictly real-world experience.                     | Real-world experience **plus** simulated planning.                                                     |
| **Data Efficiency**    | Low; requires millions of real iterations to learn. | High; learns significantly more from fewer real iterations.                                            |
| **Computation**        | Low; fast updates per real-world step.              | Higher; pauses between real steps to run simulations.                                                  |
| **Analogy**            | A student who only learns by failing actual exams.  | A student who takes one exam, figures out the teacher's style, and studies via practice tests at home. |
related note: [[Model-Free vs. Model-Based RL]]

### A Major Limitation: The "Delusion" Trap

Dyna-Q is highly vulnerable to the **"Garbage In, Garbage Out"** principle. If the agent's internal model of the world is inaccurate—which frequently happens early in training or if the environment suddenly changes—the agent will spend its planning steps reinforcing completely false assumptions.

For example, if a changing environment opens a new shortcut, a standard Dyna-Q agent may remain completely blind to it because its internal model keeps simulating the old layout, effectively brainwashing itself with outdated information until it accidentally stumbles into the new reality during a real-world exploration step.
