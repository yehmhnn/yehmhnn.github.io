Off-Policy Learning: "Learning from observing"

In off-policy methods, the agent learns about the value of an optimal target policy, while potentially following a different, more exploratory behavior policy.

- **The Concept:** 
	- The agent separates the "behavior policy" (which explores) from the "target policy" (which is the optimal one the agent is trying to learn).
    
- **How it works:** 
	- The agent can learn from data generated by a completely different agent, human demonstrations, or its own past experiences, even if it was acting more randomly at the time. 
	- It updates its values assuming it will take the _best_ possible action in the future ($max_a Q(s,a)$), regardless of what action it _actually_ takes next.
    
- **Typical Example:** **[[Q-Learning]]**. 
	- Q-Learning learns the value of the greedy (optimal) policy, even if the agent is still using an $\epsilon$-greedy strategy to explore the environment.
    
- **Key Trade-off:** 
	- Off-policy methods are more powerful because they can learn the "best" path directly, even while the agent is still acting somewhat randomly. 
	- However, this can be riskier; as seen in the [[Cliff Walking]] example, Q-learning might learn the optimal path along a cliff edge but still fall off occasionally because its behavior policy includes random exploration.
    

| **Feature**            | **On-Policy (e.g., [[SARSA]])**   | **Off-Policy (e.g., [[Q-Learning]])** |
| ---------------------- | --------------------------------- | ------------------------------------- |
| **What is evaluated?** | The policy being used             | The optimal greedy policy             |
| **Exploration**        | Included in evaluation            | Separate from evaluation              |
| **Primary Advantage**  | Safer; accounts for real behavior | Learns the optimal target directly    |
